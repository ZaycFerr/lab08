# lab08 - Использование Docker для сборки и CI/CD

![CMake Build](https://github.com/ИМЯ_ПОЛЬЗОВАТЕЛЯ/lab08/actions/workflows/ci.yml/badge.svg)

Проект по автоматизации сборки C++ приложения логирования с использованием Docker-контейнеров и непрерывной интеграции GitHub Actions.

## Компоненты приложения
* **Static C++ library** с поддержкой сборки через CMake.
* **Dockerfile** для создания изолированного окружения сборки.
* **GitHub Actions Workflow** для автоматического тестирования проекта.
